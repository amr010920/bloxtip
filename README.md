# bloxtip - Website

This is the official website for **bloxtip**, a Roblox revival inspired by Bloxxia.

## Website Features

### 🎮 Game Showcase
- Display of featured games with thumbnails and descriptions
- Quick play buttons for easy access
- Support for multiple game cards in a responsive grid layout

### 👤 Character Customization
- Show avatar customization options
- Display available cosmetics and accessories
- Preview character designs

### 📅 Events Section
- Upcoming events calendar
- Event details and descriptions
- Community engagement tracking

### 📰 News & Updates
- Latest news and patch notes
- Community highlights and spotlights
- Server maintenance announcements

### 👥 Community Hub
- Community statistics (player count, games available, uptime)
- Call-to-action for joining the community
- Social media integration links

### 🎨 Modern Dark UI
- Sleek dark theme inspired by modern gaming platforms
- Smooth animations and transitions
- Fully responsive design for mobile and desktop

## How to Use

1. Open `index.html` in your web browser
2. Navigate through different sections
3. Click on games to play
4. Click "Join Now" or "Start Playing Now" to register
